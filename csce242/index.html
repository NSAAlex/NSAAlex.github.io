Web Development course teaches students how to design and build websites using HTML, CSS, and JavaScript. Students learn web design, programming, responsive layouts, and how to create functional websites through hands-on projects.

Assignments

Assignment 1 – Basic HTML

This assignment focused on writing clean, semantic HTML from scratch. I structured a page using proper heading levels, lists, and links before any styling was added, which forced me to think about document structure separately from appearance.

Assignment 2 – Basic CSS

Here I took the HTML skeleton from Assignment 1 and applied CSS for the first time: colors, fonts, spacing, and borders. It was my first real practice separating content from presentation using an external stylesheet.

Assignment 3 – Page Layout with Flex

This assignment introduced Flexbox to build a multi-column page layout. I practiced arranging sections side by side, controlling alignment and spacing, and making the layout adapt to different screen sizes.

Assignment 4 – Recreate CSS page

In this assignment I built a responsive page layout that adapts to different screen sizes. I used the university of south carolina School of Medicine page to adjust the layout and styling for mobile, tablet, and desktop views.

Assignment 5 – Introduction to JavaScript

This assignment introduced me to JavaScript, allowing me to add interactivity to my web pages. I learned how to manipulate the DOM, handle events, and create dynamic content that responds to user actions.

Projects

Part 1 – Topic Proposal

For my project I chose Tri-Shield Security as my topic. This first part outlines the concept and scope of the project in a short PDF proposal that lays the groundwork for the site I'll be building throughout the semester.

Part 2 – Wireframe

In this part I created a wireframe for the Tri-Shield Security website. The wireframe is a visual guide that represents the skeletal framework of the site, showing the layout and structure of each page.

Part 3 – Wireframes Completed

This is part 3 of the project, where I completed the wireframes for the Tri-Shield Security website. The wireframes now include all pages and elements, providing a comprehensive blueprint for the site's design and functionality.

Part 4 – Homepage

In this part I built the homepage for the Tri-Shield Security website. The homepage serves as the main entry point for visitors, providing an overview of the company's services and a clear path to explore further.
